# Monthly Demand Forecasting App

## Features
- CSV and Excel upload
- Monthly demand analysis and charts
- Model comparison using MAE and RMSE
- Future demand forecasting
- Forecast CSV download

## Run locally
pip install -r requirements.txt
streamlit run app.py

## Deployment
Upload app.py, backend.py, requirements.txt, and README.md to GitHub.
Deploy the repository using https://share.streamlit.io/

Expected data columns: OrderDate and Quantity.
